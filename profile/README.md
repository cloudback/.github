# Cloudback

[Cloudback](https://cloudback.it/) is a SOC 2 Type II compliant backup and restore platform for **GitHub, GitLab, Azure DevOps, and Linear**. Engineering, DevOps, and security teams use Cloudback for compliance audit prep, ransomware recovery, accidental-deletion rollback, and platform migration.

**Trusted by 1.7k+ customers to protect 14k+ repositories with 4M+ backups created.**

## What Cloudback offers

- **Automated daily backups** of repository content (full Git history + Git LFS), pull requests, issues, project data, and platform metadata.
- **AES-256 encrypted ZIP archives** with double-archive filename protection. Optional **customer-managed encryption keys (RSA Lockbox / CMEK)** so backup contents stay readable only to the holder of the private key.
- **Bring your own storage** across 10 configurations: Amazon S3 (access key, access point, Glacier), Microsoft Azure Blob, Google Cloud, Microsoft OneDrive (Business and Personal), Wasabi, Alibaba OSS, OpenStack Swift. Or use Cloudback-managed regions in 5 geographies (US, EU, UK, Sydney, Singapore).
- **Self-service restore** to the same repository, a different repository, or a different account. Bulk restore for disaster-recovery scenarios. **Cross-platform restore** between GitHub and GitLab for migration.
- **Compliance evidence** with SOC 2 Type II attestation, an audit log spanning 60+ event types (CSV export or SIEM forwarding), and Vanta integration for access reviews.
- **Notifications** via Slack, Microsoft Teams, and Discord webhooks (success, failure, daily summary), plus a daily email listing failed automatic backups.
- **Built for automation**: Terraform provider, Operations API, and an MCP server for Claude Code, Cursor, and other AI assistants.
